# High-Frequency Feishu Table Templates

Use these templates for recurring business workflows.

## Usage Rule

1. If task is temporary: pick any template and trim columns.
2. If task is long-term: keep the template header order stable.
3. Confirm `sheet + startCell + overwrite/append` before writing.

## 1) AI Model Comparison (high frequency)

When:

1. Tool/model evaluation.
2. Procurement and pilot comparison.

Headers:

1. `模型`
2. `核心优势`
3. `主要局限`
4. `适用场景`
5. `成本级别`
6. `结论`

## Long-Term Stability Checklist

1. Header row frozen.
2. Filter enabled.
3. Status/priority columns use dropdown validation.
4. Date columns use unified date format.
5. New columns added only with explicit confirmation.
