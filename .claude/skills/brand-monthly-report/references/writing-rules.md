# Writing Rules

## Tone

1. Use Chinese office-report style
2. Keep claims proportional to evidence
3. Prefer neutral business phrasing over dramatic phrasing
4. If an issue is real but not severe, describe it mildly

Recommended pattern:

1. state the fact
2. explain the likely meaning
3. close with a restrained conclusion

For word clouds and similar semantic summaries:

1. check whether high-frequency terms fit the brand's core tone first
2. if tone fit is weak, say so directly but mildly
3. do not force a positive or brand-centered interpretation when semantics are off

## Formatting

1. Use bold for:
   - key metrics
   - date windows
   - brand names
   - section-level takeaways
2. Use bullets when the content is naturally list-shaped
3. Use short tables when the template already expects a table
4. Avoid long undifferentiated paragraphs

## Template discipline

1. If the user says to follow the template strictly, keep the same structure
2. If the user says to optimize structure, improve readability but keep month-to-month comparability
3. If the prior template uses a fixed table schema, do not replace it with prose

## Brand relevance standard

Classify article relevance as:

1. `direct`: brand or product explicitly named in body text or credited in images
2. `indirect`: category content with brand appearing as one example product
3. `irrelevant`: same word string but different semantic domain

Use only `direct` and stronger `indirect` cases as monthly report evidence.
