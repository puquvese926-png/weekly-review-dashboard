# Section Playbook

## 2.2 Volume Trend

Use:

1. one summary sentence for the month
2. bullets for major peaks
3. anomaly note if a peak is inflated by mis-entry

Preferred pattern:

- `Peak A`: date, count, cause
- `Peak B`: date, count, cause

## 2.3 Key Media Sources

Use:

1. one short summary about concentration
2. bullets for top outlets or groups
3. one closing line on concentration or distribution

## 2.4 SOV

Use two fixed blocks:

1. `overall volume summary`
2. `competitor comparison`

In `competitor comparison`, group brands into tiers if that improves readability.

## 2.5 Top Competitor Content

Do not only describe the article. Explain why it matters.

Use:

1. brand heading
2. `content analysis`
3. `propagation takeaways`

Cover:

1. article type and scenario
2. how the brand appears
3. why the content has propagation value
4. what direction is worth paying attention to

## 3.1 Overall Social Metrics

Use:

1. one lead sentence
2. bullets for mentions, reach, impressions, unique authors

## 3.2 Mention Trend

Use:

1. one lead sentence
2. bullets for peaks
3. bold the strongest peak and key counts

## 3.3 Word Cloud

Run a tone-fit validation before interpretation.

Classify top words into three buckets:

1. direct nail or beauty words
2. adjacent seasonal or lifestyle words
3. unrelated or off-tone words

Use:

1. one paragraph plus bullets
2. describe semantic clusters gently
3. state whether the cloud broadly fits nail-brand tone
4. if unrelated terms dominate, do not force a strong brand interpretation
5. if the cloud is mixed, state that representativeness is limited

## 3.4 Negative Comments

Use the prior table schema:

| Negative Type | Specific Issue | Example Text |
|---|---|---|

Do not convert this section into timeline prose when the template expects a table.

## 3.5 Platform Distribution

Keep concise.

Use:

1. dominant platform
2. second platform if meaningful
3. one short closing sentence

## 3.6 Hashtag

Use:

1. one summary line
2. 3 to 5 bullets for important tags
3. one line on topic diversity or content direction

## 3.7 Top Authors

Use:

1. one short ranking summary
2. one line on account type mix
3. mention reach only if it materially changes interpretation

## 3.8 Competitor Report

Use a repeated brand block so cross-brand comparison stays clean:

1. `core metrics`
2. `content traits`
3. `brief judgment`
4. `propagation takeaways`

For each competitor, keep the same subheading order.
