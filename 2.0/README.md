# 周复盘独立看板 2.0

## 版本目标

2.0 是周复盘看板的独立新版，保留现有图表、表格和指标计算逻辑，但改成分页面展示。

重点变化：

- 顶部导航从滚动定位改为页面切换。
- 总览、生命周期、渠道、内容、站外、声量拆成独立视图。
- 页面改成全局工作台布局，减少大面积卡片堆叠。
- 新增复盘结束日选择。
- 新增主题切换，包含墨蓝、粉釉、青瓷、鎏金四套主题。

## 数据口径

- 内容池仍为复盘结束日前 30 天发布的帖子。
- 当前周仍按复盘结束日倒推 7 天计算。
- 上周仍按当前周期向前平移 7 天计算。
- 图表、表格和指标计算函数沿用 1.0 版本。
- 导入逻辑仍要求 `发布时间` 和 `统计日期` 为必填，缺失行会跳过。

## 使用方式

直接打开：

- `output/weekly-review-dashboard/2.0/index.html`

页面顶部可以完成：

- 切换模块页面
- 调整复盘结束日
- 切换一级渠道和二级平台
- 切换折线图粒度
- 切换主题色
- 导入 Excel/CSV 或恢复内置数据

## 文件说明

- `index.html`：2.0 页面结构
- `styles.css`：2.0 全局工作台视觉
- `app.js`：页面切换、主题、时间选择和原有计算逻辑
- `review-mock-data.js`：内置数据
- `COLLAB.md`：协作约定
- `TASKS.md`：任务板
